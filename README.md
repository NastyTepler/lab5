# Лабораторная работа №5. Stream API, Gson и Lombok

**Автор:** Теплякова Анастасия Владимировна  
**Группа:** ФИТ-251

## Что реализовано
1. Чтение JSON файла `books.json` с помощью библиотеки Gson.
2. Генерация классов `Book`, `Visitor`, `SmsMessage` с помощью аннотаций Lombok (`@Data`, `@AllArgsConstructor`, `@NoArgsConstructor`).
3. Обработка данных с помощью Stream API:
    - Вывод списка посетителей (Задание 1).
    - Вывод уникальных книг (Задание 2).
    - Сортировка книг по году издания (Задание 3).
    - Поиск книг автора "Jane Austen" (Задание 4).
    - Поиск максимального количества книг у одного посетителя (Задание 5).
    - Генерация SMS-сообщений для подписчиков на основе среднего количества книг (Задание 6).

## Инструкция по запуску
1. Убедитесь, что в корне проекта есть папка `data` с файлом `books.json`.
2. Запустите метод `main` в классе `app.Lab5App` из вашей IDE.
